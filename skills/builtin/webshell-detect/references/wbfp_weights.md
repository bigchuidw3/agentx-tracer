## 主要差异及原因

| 差异 | 原因 |
|------|------|
| PHP Obfuscation 暴增 (0.72) | Webshell 平均 22 个混淆函数，白样本仅 0.07，比值 311x |
| JSP Code Exec 偏低 (0.07) | JSP Webshell 更依赖 Program Exec（Runtime.exec）而非反射执行 |
| ASP Code Exec 几乎无区分力 (0.02) | Eval/Execute 在正常 ASP 中同样常见（22% vs 19%） |
| ASP Network 暴增 (0.56) | 白样本几乎无网络调用（0.8%），Webshell 中 C2 通信常见（27.5%） |

† 标记表示白样本该类别命中率为 0，r_c/r_f/r_u 被截断到上限 200。
JSP 白样本极干净（仅 1.6% 有调用），导致 4 类触发截断，真实区分力可能更高。
