基本信息

用户 ID：当前登录用户的唯一标识（userId），在 Opik 里按 opik.metadata.userId 筛选自己的链路。

调用 ID：本次任务执行的唯一标识（sessionId）。一次任务可能包含多轮推理和多次工具调用，但只对应一个调用 ID。

会话 ID：对话窗口的唯一标识（conversationId）。一个会话窗口内可以连续发起多次任务请求，因此一个会话 ID 通常对应多条调用 ID。
